How it works

  1. 1

    Upload

    Drop in an sshd log from Debian, Ubuntu, RHEL or any server that writes auth.log or secure. Both classic and ISO timestamps work.

  2. 2

    Analyze

    Four detection rules run over the events in memory. Thresholds and time windows are yours to change.

  3. 3

    Visualize

    A dashboard shows severity, failed versus successful logins, activity over time and the busiest source addresses.

  4. 4

    Report

    Download a branded PDF, a self-contained HTML report, CSV or JSON, or pull the same result from the REST API.

What you get

Explainable findings

Every finding shows its evidence, the rule and threshold that fired, why it matters and the defensive action to take. Nothing is called a confirmed attack.

Security analytics

Severity distribution, event types, failed versus successful logins, activity over time and top source addresses, all drawn from your log.

Filter and search

Narrow findings and events by severity, detection, hour or text. Click a chart to filter. Works without JavaScript.

Reports and API

PDF with charts, HTML, CSV and JSON, plus a documented REST API for scripts and CI.

Private by design

The raw log is analyzed in memory and discarded. Output is escaped and a strict Content Security Policy blocks injected scripts.

Built to be checked

Open source, with automated tests, linting and a container build on every push. The security review lists what is and is not covered.

What an attack looks like in a log

These lines come from the sample log. Each group is a different detection.

What it checks

Brute force
Many failed logins from one address against one account within a few minutes. T1110.001
Password spraying
One address trying many different accounts, hoping one has a weak password. Critical if that address later logs in. T1110.003
Likely account takeover
A login succeeds right after repeated failures for the same account and address. T1078
Admin login from outside
root, admin or another privileged account signing in from outside your internal network. T1078
